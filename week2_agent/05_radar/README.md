# 第 2 周任务 1：异动对比（招牌功能 ⭐）

## 功能说明

从"单次提取"升级到**批量提取 → 存储 → 对比 → 报警**的完整闭环。

## 核心流程

```
三家公司的 2024 + 2025 年报
↓ batch_extract()
逐个问题提取指标（工业富联 / 紫金矿业 / 兴业银行）
↓ pydantic 校验 + 单位换算
写入 SQLite（data/metrics.db）
↓ compare_report()
同比计算（亿元类用百分比，比率类用百分点）
↓ 异动标记（阈值：±20% 或 0.25 个百分点）
📡 异动雷达报告
```

## 核心知识点

| 知识点 | 说明 |
| :--- | :--- |
| **SQLite** | 轻量级数据库，单文件存储（data/metrics.db） |
| **CREATE TABLE IF NOT EXISTS** | 幂等建表，多次运行不报错 |
| **批量提取** | 双层循环遍历「公司 × 年份 × 问题」 |
| **指标名称标准化** | `normalize_indicator_name()` 统一口径 |
| **单位换算** | 换算放在代码里（确定性计算），不靠大模型 |
| **同比计算** | `(v25 - v24) / v24 * 100` |
| **异动阈值** | 亿元类 ≥20%、比率类 ≥0.25pp 触发 ⚠️ |
| **`__name__` 门** | 直接运行出报告；被 6 号 import 时只提供函数 |
| **`import radar`** | 6 号以 `import radar` 复用本模块能力，所以文件命名为 radar.py（main.py 不能当模块名） |
